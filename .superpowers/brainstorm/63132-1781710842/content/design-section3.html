Design — Seção 3: FeedFetcher, FeedParser & Auto-Discovery

As duas primeiras camadas do pipeline + como adicionar feeds

FeedFetcher

Responsável por todo HTTP I/O. Usa URLSession (nativo do Foundation, sem dependências).

final class FeedFetcher {
    // MARK: - Feed Fetching
    func fetch(subscription: FeedSubscription) async throws → (Data, HTTPURLResponse)
    // Sends conditional GET with ETag + Last-Modified
    // Returns 304 Not Modified → no new items

    // MARK: - URL Auto-Discovery
    func discoverFeed(from url: URL) async throws → [URL]
    // 1. Fetch the page HTML
    // 2. Parse <link rel="alternate" type="application/rss+xml">
    // 3. Resolve YouTube @handle → channel ID → RSS URL
    // 4. Return discovered feed URLs

    // MARK: - OPML Import
    func parseOPML(_ data: Data) throws → [OPMLOutline]
    // Parse OPML XML → flat list of feed URLs with folder names as tags
}

FeedParser — RSS 2.0 + Atom 1.0

Usa XMLParser (Foundation SAX parser). Um parser unificado que detecta o formato pelo root element.

enum FeedParser {
    static func parse(data: Data, sourceURL: String) throws → FeedParseResult
}

struct FeedParseResult {
    let title: String?           // feed-level title
    let description: String?    // feed-level description
    let link: String?           // feed-level homepage
    let items: [FeedItem]       // parsed items
}

// Suporte mínimo mas robusto:
// RSS: title, link, description, pubDate, author, category, enclosure, guid
// Atom: title, link[@rel=alternate], summary/content, published/updated,
//        author/name, category[@term], link[@rel=enclosure]
// Namespace extensions ignorados no MVP (mrss, itunes, etc.)
// YouTube: enclosure vira enclosureURL; media:group ignorado no MVP
Auto-Discovery Flow — YouTube Example
User pastes:  https://www.youtube.com/@3blue1brown
                     │
                     ▼
discoverFeed(from:)
  1. Fetch page HTML
  2. Find: <meta itemprop="channelId" content="UCYO_jab_esuFRV4b17AJtAw">
  3. Build: https://www.youtube.com/feeds/videos.xml?channel_id=UCYO_jab...
                     │
                     ▼
Returns:  [URL("https://www.youtube.com/feeds/videos.xml?channel_id=...")]

User pastes:  https://example.com/blog
                     │
                     ▼
discoverFeed(from:)
  1. Fetch page HTML
  2. Find: <link rel="alternate" type="application/rss+xml" href="/feed.xml">
  3. Resolve relative URL → absolute
                     │
                     ▼
Returns:  [URL("https://example.com/feed.xml")]
