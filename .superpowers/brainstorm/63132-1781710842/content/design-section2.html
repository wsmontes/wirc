Design — Seção 2: Modelos de Dados

FeedItem intermediário, mapeamento WOM types, e FeedSubscription

FeedItem — Struct Intermediário

Representa um item parseado de qualquer feed (RSS ou Atom) antes de virar WOM. É o "IRCMessage" do pipeline de feeds.

struct FeedItem: Codable, Equatable {
    // Required (every feed format has these)
    let id: String           // guid (RSS) or id (Atom), fallback: link
    let title: String
    let link: String          // canonical URL
    let description: String? // plain text or HTML summary
    let publishedAt: Date?

    // Optional enrichment
    let author: String?
    let category: String?
    let enclosureURL: String?   // media: image, audio, video
    let enclosureType: String? // MIME type
    let duration: String?      // podcast/YouTube
}

Mapeamento FeedItem → WOM Types

O contexto da fonte (não o formato do feed) determina o WOM type. YouTube RSS e blog RSS usam o mesmo parser, mas o Adapter aplica o type correto baseado na subscription.

Fonte WOM type Card no Feed
Blog / News site [wom:Post] Título + descrição + link
YouTube channel [wom:Post, external.youtube.video] Thumbnail + título + link ao vídeo
Podcast [wom:Post, external.podcast.episode] Capa + título + duração + player
GitHub releases [wom:Post, external.github.release] Versão + changelog + link
Newsletter (Substack, etc.) [wom:Post] Título + corpo + link

FeedSubscription — O que o usuário segue

struct FeedSubscription: Codable, Identifiable, Equatable {
    let id: UUID
    var feedURL: String           // https://example.com/feed.xml
    var title: String              // "Wagner's Blog" (parsed from feed)
    var sourceType: FeedSourceType // .rss, .atom, .youtube, .github, .podcast
    var tags: [String]            // user + AI assigned: ["tech", "llm", "brasil"]
    var lastFetchedAt: Date?
    var etag: String?              // HTTP ETag for conditional GET
    var lastModified: String?     // HTTP Last-Modified
    var errorCount: Int          // consecutive failures (for auto-pause)
}

enum FeedSourceType: String, Codable {
    case rss, atom, youtube, github, podcast
}
