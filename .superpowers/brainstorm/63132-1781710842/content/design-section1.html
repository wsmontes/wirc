Design — Seção 1: Arquitetura & Componentes

RSS Feed Reader como pipeline de 4 camadas, espelhando o padrão IRC existente

Data Flow — RSS → WOM → UI
HTTP GET feed.xml
       │
       ▼
┌──────────────────────────────┐
│  FeedFetcher                  │  <── Schedule (BGTask / manual / on-launch)
│  • URLSession async fetch    │
│  • ETag / Last-Modified      │
│  • OPML parsing              │
└──────────────┬───────────────┘
               │ raw XML data
               ▼
┌──────────────────────────────┐
│  FeedParser                   │
│  • RSS 2.0 parsing           │
│  • Atom 1.0 parsing          │
│  • XMLParser (Foundation)    │
└──────────────┬───────────────┘
               │ [FeedItem] (intermediate struct)
               ▼
┌──────────────────────────────┐
│  FeedToWOMAdapter            │
│  • FeedItem → WOMObject      │
│  • Type mapping per feed     │
│  • Canonical URL preservation│
└──────────────┬───────────────┘
               │ [WOMObject]
               ▼
┌──────────────────────────────┐
│  WOMStore (JSONFileStore)    │
│  • Persistent on disk        │
│  • Query by WOM type         │
│  • Dedup by canonical URL    │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│  FeedView + FeedCard          │
│  • Renders wom:Post cards    │
│  • Pull-to-refresh           │
│  • Unread indicators         │
└──────────────────────────────┘

Novos Arquivos

Arquivo Responsabilidade
FeedFetcher.swift HTTP fetch com ETag, OPML import, URL auto-discovery
FeedParser.swift XMLParser-based RSS 2.0 + Atom 1.0 → [FeedItem]
FeedItem.swift Struct intermediário: title, link, description, pubDate, author, enclosure
FeedToWOMAdapter.swift FeedItem → WOMObject com type mapping por fonte
FeedSubscription.swift Model: feed URL, title, category/tags, lastFetched, ETag
FeedSubscriptionStore.swift CRUD de subscriptions, JSON file persistence
JSONFileStore.swift Implementação persistente do WOMStore (adiada do MVP)
