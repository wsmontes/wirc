FeedToWOMAdapter

Espelha o IRCToWOMAdapter. Recebe [FeedItem] + FeedSubscription, produz [WOMObject].

final class FeedToWOMAdapter {
    func convert(
        items: [FeedItem],
        subscription: FeedSubscription
    ) → [WOMObject]

    // Type mapping depende do sourceType da subscription:
    // .rss/.atom    → [wom:Post]
    // .youtube      → [wom:Post, external.youtube.video]
    // .github       → [wom:Post, external.github.release]
    // .podcast      → [wom:Post, external.podcast.episode]
}

Cards do Feed por Tipo

Cada WOM type tem um layout de card diferente. O FeedCard faz switch pelo type.

Tipo Layout Elementos
wom:Post (blog) Card textual Título, resumo, autor, data, fonte
youtube.video Card com thumbnail Thumbnail esquerda, título, canal, duração
podcast.episode Card com capa Capa, título, podcast, duração, botão play
github.release Card compacto Tag de versão, repo, changelog resumido
