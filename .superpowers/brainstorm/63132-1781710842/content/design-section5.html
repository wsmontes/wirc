Design — Seção 5: Background Refresh, Settings & AppState

Infraestrutura de refresh, UI de gerenciamento, e o que muda no AppState

Background Refresh — BGAppRefreshTask

iOS permite agendar uma tarefa de background que o sistema executa quando achar oportuno (bateria, conectividade, horário). Não é um timer preciso — é uma sugestão.

// Registrar no App init:
BGTaskScheduler.shared.register(
    forTaskWithIdentifier: "com.wirc.feed-refresh",
    using: nil
) { task in
    // Fetch all subscriptions, convert to WOM, save
    await appState.refreshAllFeeds()
    task.setTaskCompleted(success: true)
    // Re-schedule for next time
    appState.scheduleNextRefresh()
}

// Schedule next refresh (call after each successful run):
let request = BGAppRefreshTaskRequest(
    identifier: "com.wirc.feed-refresh"
)
request.earliestBeginDate = Date().addingTimeInterval(30 * 60)
try BGTaskScheduler.shared.submit(request)

// Também fazemos fetch em:
// - App launch (viewDidAppear / onAppear do FeedView)
// - Pull-to-refresh no FeedView
// BGTask é só o bônus — o usuário nunca depende dele
