# WOM 0.7 Lite + Crypto — Design Spec

**Status:** approved | **Date:** 2026-06-19 | **Version:** 1.0

## Overview

Upgrade WOM from 0.6 to 0.7 with canonical hashing, Ed25519 signatures, WOM Lite
compact transmission, pseudonymous addresses, hashed version chaining, and encrypted
payloads. Foundation for Wirc-to-Wirc sync, mesh transmission, and trust model.

## 1. New WOMObject fields

| Field | Type | Purpose |
|-------|------|---------|
| `wom` | String | `"0.6"` → `"0.7"` |
| `_lite` | WOMLite? | Compact transmission metadata |
| `_encrypted` | WOMEncryptedPayload? | Encrypted content payload |
| `address` | String? | Pseudonymous author address (ripemd160(sha256(pubkey))) |
| `expiresAt` | Date? | Top-level expiration |
| `languages` | [String]? | BCP 47 language tags |

### Revision upgrade

Existing `revision: [String: String]?` becomes a typed struct:

```swift
struct WOMRevision: Codable, Equatable {
    var version: Int
    var hash: String?            // "sha256:..."
    var previousHash: String?
    var previousSignature: String?
    var updatedAt: Date?
    var updatedBy: String?
}
```

## 2. WOM Lite

Compact format for network transmission (~150 bytes vs ~800 full).

```swift
struct WOMLite: Codable, Equatable {
    var fullHash: String          // "sha256:..."
    var fullSize: Int             // bytes
    var version: Int
    var previousHash: String?
    var previousSignature: String?
    var fields: [String]?         // top-level field names omitted from Lite
}
```

A WOM Lite object carries: `wom`, `id`, `type`, `createdAt`, `attributedTo`, `content`, `governance`, `data`, `_lite`. All other fields are omitted and listed in `_lite.fields`.

## 3. Canonicalizer

```swift
enum WOMCanonicalizer {
    /// Produce canonical JSON bytes for deterministic hashing.
    /// - Recursively sorts keys alphabetically
    /// - No whitespace, no indentation
    /// - Excludes _lite and _encrypted
    /// - Unicode NFC normalized
    static func canonicalize(_ object: WOMObject) throws -> Data

    /// sha256 of canonical JSON.
    static func hash(_ object: WOMObject) throws -> String  // "sha256:hex..."
}
```

## 4. Crypto (Ed25519 via CryptoKit)

```swift
enum WOMCrypto {
    /// Sign a WOMObject with Ed25519 private key.
    /// Returns the base64-encoded signature.
    static func sign(_ object: WOMObject, privateKey: Curve25519.Signing.PrivateKey) throws -> String

    /// Verify an Ed25519 signature against a WOMObject.
    static func verify(_ object: WOMObject, signature: String, publicKey: Curve25519.Signing.PublicKey) -> Bool

    /// Generate pseudonymous address: ripemd160(sha256(pubkey)).
    /// Uses SHA256-truncated-to-20-bytes as initial implementation
    /// (full RIPEMD160 can be added later as pure Swift).
    static func address(_ publicKey: Curve25519.Signing.PublicKey) -> String

    /// Encrypt content + data fields for restricted sharing.
    /// Returns WOMEncryptedPayload with XChaCha20-Poly1305.
    static func encrypt(_ object: WOMObject, recipients: [Curve25519.KeyAgreement.PublicKey]) throws -> WOMEncryptedPayload

    /// Decrypt content + data from encrypted payload.
    static func decrypt(_ payload: WOMEncryptedPayload, privateKey: Curve25519.KeyAgreement.PrivateKey) throws -> (content: WOMContent?, data: [String: String]?)
}
```

**Dependencies:** CryptoKit (iOS 13+, native). No external packages.

## 5. Version Chain

Each version hashes the previous hash + previous signature:

```
V1: hash1 = sha256(canonical_v1), sig1 = sign(hash1, key)
V2: hash2 = sha256(canonical_v2 + hash1 + sig1), sig2 = sign(hash2, key)
```

`revision.previousSignature` carries the prior version's signature, closing the chain. Verifying the latest version = verifying the entire chain.

## 7. Success Criteria

1. WOMObject.wom = `"0.7"`
2. Canonicalizer produces deterministic JSON (same input → same hash)
3. Ed25519 sign/verify works end-to-end
4. WOM Lite carries ~8 fields + `_lite` with hash
5. Version chain: V2 hash includes V1 hash + V1 sig
6. Address generation is deterministic
7. Build: 0 errors, CryptoKit linked, no external deps
8. Backward compatible: old WOMObject JSON decodes with new fields as nil
